# WanderLust 🌍✈️

WanderLust is a modern, premium travel companion application built with Next.js 16 and Tailwind CSS. It helps users discover breathtaking destinations and seamlessly plan their trips by integrating directly with Google Calendar.

## Features

-   **Curated Destinations**: Explore a list of hand-picked, stunning travel locations.
-   **Premium UI**: Experience a visually immersive interface with glassmorphism, smooth animations, and a dark-themed aesthetic.
-   **One-Click Planning**: Instantly add trip details (dates, location, description) to your Google Calendar with a single click.
-   **Responsive Design**: Optimized for all devices, from desktops to mobile phones.

## Tech Stack

-   **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
-   **Language**: TypeScript

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd wanderlust
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Open your browser:**
    Navigate to [http://localhost:3000](http://localhost:3000) to see the app in action.

## Project Structure

-   `src/app`: Main application routes and pages.
-   `src/components`: Reusable UI components (e.g., `DestinationCard`).
-   `src/data`: Mock data for destinations.
-   `src/utils`: Utility functions (e.g., Google Calendar URL generator).
-   `src/types`: TypeScript definitions.
